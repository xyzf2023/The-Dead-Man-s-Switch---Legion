# 模块化操作界面 - 基础框架

## 文件说明

### ModularOperationWindow.cs
主窗口类，实现了模块化操作界面的基础框架。

**功能特性：**
- ✅ 左右两栏布局（3:1比例）
- ✅ 左侧区域：
  - 建筑槽位网格（2行4列，8个正方形槽位）
  - 功能按钮区域（4个按钮，2行2列：生产规划、战术支援、机械体管理、战略部署）
  - 资源展示区域（底部，不可点击）
- ✅ 右侧区域：任务队列面板
- ✅ 所有按钮可点击，点击后显示中文消息反馈
- ✅ 空槽点击后展开额外窗口（占位实现）

### TestEntry.cs
测试入口文件，提供打开窗口的方法。

### ClusterConstructionCommTarget.cs
集群建设通讯目标类，实现`ICommunicable`接口。

**功能特性：**
- ✅ 实现`ICommunicable`接口，用于在通讯台联络列表中显示
- ✅ 提供"集群建设"选项文本和描述
- ✅ 点击后打开`ModularOperationWindow`窗口

### Patch_CommsConsole_GetCommTargets.cs
Harmony补丁文件，为通讯台添加集群建设联络选项。

**功能特性：**
- ✅ 拦截`Building_CommsConsole.GetCommTargets`方法
- ✅ 在联络列表中添加`ClusterConstructionCommTarget`选项
- ✅ 选项会显示在右键菜单的派系列表中

## 使用方法

### 在游戏中测试

1. **通过控制台命令打开窗口**：
   ```
   在游戏控制台中输入：
   Find.WindowStack.Add(new ClusterConstruction.ModularOperationWindow());
   ```

2. **或者通过代码调用**：
   ```csharp
   ClusterConstruction.TestEntry.OpenModularOperationWindow();
   ```

3. **通过通讯台打开（推荐）**：
   - 选中一个小人
   - 右键点击通讯台
   - 在派系列表中选择"集群建设"
   - 窗口会自动打开

### 注意事项

**需要添加翻译键**：
在MOD的翻译文件中添加以下键值：

```xml
<LanguageData>
  <DMSL_ClusterConstruction>集群建设</DMSL_ClusterConstruction>
  <DMSL_ClusterConstructionDesc>打开集群建设管理界面</DMSL_ClusterConstructionDesc>
</LanguageData>
```

**需要注册Harmony补丁**：
确保在MOD的Harmony初始化代码中加载了`Patch_CommsConsole_GetCommTargets`补丁。
如果使用`harmony.PatchAll()`自动扫描，补丁会自动加载。

## 按钮点击反馈

所有按钮点击后会显示中文消息：

- **建筑槽位**：点击空槽显示"点击了空槽位 X"，点击已填充槽位显示"选中了建筑槽位 X"
- **生产规划按钮**：显示"点击了生产规划按钮"
- **战术支援按钮**：显示"点击了战术支援按钮"
- **机械体管理按钮**：显示"点击了机械体管理按钮"
- **战略部署按钮**：显示"点击了战略部署按钮"
- **关闭按钮**：显示"关闭了模块化操作界面"或"关闭了建筑选择窗口"
